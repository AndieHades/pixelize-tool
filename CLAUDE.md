# CLAUDE.md — гид для агентов

Pixel Heart — пиксель-арт редактор (PWA). Чистый фронтенд: `index.html` +
модули + service worker + иконки. Ни сборки, ни рантайм-зависимостей —
файлы отдаются как есть (GitHub Pages).

## Прежде чем писать код — прочти

1. **[docs/conventions.md](docs/conventions.md)** — жёсткие правила (лимит строк,
   границы систем, запрет дублирования). Это контракт, а не пожелания.
2. **[docs/architecture.md](docs/architecture.md)** — слои, поток данных, модель документа.
3. **[docs/systems.md](docs/systems.md)** — карта модулей: где что лежит и кто за что отвечает.
4. **[docs/utilities.md](docs/utilities.md)** — каталог переиспользуемого. **Загляни сюда
   перед тем как писать любой помощник — почти наверняка он уже есть.**

## Золотые правила (полностью — в conventions.md)

- **≤ 170 строк на файл.** Подходишь к лимиту — дроби на модули.
- **Одна задача на модуль.** Нужно «и» в описании — это две системы, раздели.
- **Системы не импортируют друг друга.** Общение только через слои `state` и `bus`.
- **Логика отдельно от визуала.** Чистые функции над данными — в `src/logic/`,
  без DOM и без `state`.
- **Никакого дублирования.** Повтор → вынеси в `src/logic/` или `src/core/`.

## Проверка перед коммитом

```bash
npm test          # юнит-тесты модулей + headless smoke (jsdom), 48 проверок
```

`npm test` обязан быть зелёным. Меняешь поведение системы — добавь сценарий
в `test/probe.js` (smoke) или `test/unit.mjs` (чистая логика).

GUI в CI не запускается, поэтому интерактив (drag окон, pinch, перо)
проверяется вручную в браузере: открой `index.html`.

## Статус миграции

Идёт перевод монолита `js/*.js` (общий глобальный scope) на модули `src/*`.
Актуальный прогресс и что уже портировано — в **[docs/systems.md](docs/systems.md)**.
Пока приложение грузится из `index.html`; не переключай его на модули, пока
весь набор систем не портирован и smoke не зелёный по модульному пути.
