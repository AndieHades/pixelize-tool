# CLAUDE.md — гид для агентов

Pixel Heart — пиксель-арт редактор (PWA), тач-first.

**Продукт-ориентир (north star): «Procreate, но для пиксельной графики».**
Та же планка UX — галерея работ, жесты, слои, чистый минимальный интерфейс,
профессиональные инструменты. Решения по фичам и UI сверяй с этим.

Стек: статический фронтенд на ES-модулях, сборка **Vite** → `dist/`, деплой
на GitHub Pages через Actions. Рантайм-зависимостей нет. Сборка идёт на
деве/CI; iPad и любой браузер открывают готовые статические файлы.

## Прежде чем писать код — прочти

1. **[docs/conventions.md](docs/conventions.md)** — жёсткие правила (лимит строк,
   границы систем, запрет дублирования). Это контракт, а не пожелания.
2. **[docs/architecture.md](docs/architecture.md)** — слои, поток данных, модель документа.
3. **[docs/systems.md](docs/systems.md)** — карта модулей: где что лежит и кто за что отвечает.
4. **[docs/utilities.md](docs/utilities.md)** — каталог переиспользуемого. **Загляни сюда
   перед тем как писать любой помощник — почти наверняка он уже есть.**
5. **[docs/config.md](docs/config.md)** · **[docs/keymap.md](docs/keymap.md)** — настраиваемые
   данные и хоткеи (правила «настраиваемое → данные, не магические числа»).
6. **[docs/i18n.md](docs/i18n.md)** · **[docs/theming.md](docs/theming.md)** — локализация и
   токены тем (правила «никаких зашитых строк/стилей»).
7. **[docs/roadmap.md](docs/roadmap.md)** — куда идём: сборка, локализация, темы,
   персистентность/галерея, готовность к анимации; статус по пунктам.

## Золотые правила (полностью — в conventions.md)

- **≤ 170 строк на файл.** Подходишь к лимиту — дроби на модули.
- **Одна задача на модуль.** Нужно «и» в описании — это две системы, раздели.
- **Системы не импортируют друг друга.** Общение только через слои `state` и `bus`.
- **Логика отдельно от визуала.** Чистые функции над данными — в `src/logic/`,
  без DOM и без `state`.
- **Никакого дублирования.** Повтор → вынеси в `src/logic/` или `src/core/`.
- **Ни одной зашитой UI-строки.** Все подписи/тосты/меню — через `t('ключ')`,
  тексты живут в `src/i18n/locales/*` (см. [docs/i18n.md](docs/i18n.md)).
- **Ни одного зашитого значения стиля.** Цвета/размеры/отступы — токены
  (CSS-переменные), см. [docs/theming.md](docs/theming.md).
- **Настраиваемое — данные, не магические числа.** Пределы/пресеты/дефолты/
  тайминги — в `src/config/*`; хоткеи — карта в `systems/keyboard/keymap.js`.

## Проверка перед коммитом

```bash
npm test          # unit (чистая логика) + module-int (системы) + module-boot (загрузка app)
npm run dev       # Vite dev-сервер с горячей перезагрузкой
npm run build     # сборка в dist/
```

`npm test` обязан быть зелёным. Меняешь поведение — добавь сценарий в
`test/unit.mjs` (чистая логика) или `test/module-int.mjs` (система под jsdom).

GUI в CI не запускается, поэтому интерактив (drag окон, pinch, перо)
проверяется вручную в браузере: открой `index.html`.

## Статус

Миграция на модули **завершена**: `index.html` → `src/app.js`, монолит удалён,
`vite build` собирает `dist/`, `npm test` зелёный. Идут продуктовые фазы
(локализация, темы, персистентность/галерея) — см. [docs/roadmap.md](docs/roadmap.md).
