# Дорожная карта

North star: **«Procreate для пиксель-арта»** — галерея работ, жесты,
тач-first, чистый интерфейс, профессиональные инструменты.

Порядок продуман так, что каждый пункт опирается на предыдущий и не ломает
работающее приложение. Статус: ✅ готово · 🟡 идёт · 🔲 ждёт.

## 1. Чистая архитектура без дублей — 🟡

Перевод монолита `js/*` (общий глобальный scope) на слои `src/{logic,core,systems}`.
Прогресс и карта модулей — в [systems.md](systems.md). Сделано: слои `state`/`bus`,
DOM-фундамент, **вся чистая логика**, дедуп-утилиты, safety-net (`npm test`).

## 2. Сборка Vite + деплой — 🟡 (инфра готова, активируется в конце §1)

- `vite.config.js`, скрипты `dev`/`build`/`preview`, CI `.github/workflows/deploy.yml`.
- **Заработает, когда `index.html` перейдёт на модульную точку входа** `src/app.js`
  (Vite не бандлит классические скрипты — это проверено).
- Активация деплоя: Settings → Pages → Source → «GitHub Actions».
- На iPad ничего не меняется: открывается готовый статический `dist/`.

## 3. Локализация (i18n) — 🔲

Все UI-строки → `t('ключ')`, тексты в `src/i18n/locales/{ru,en}.js`.
ru — дефолт (текущий), en — полный перевод. Детали и правила — [i18n.md](i18n.md).
Добавить язык = один новый файл локали.

## 4. Темизация токенами — 🔲

Цвета/размеры/отступы → CSS-переменные в одном месте. Менять тему = править
токены, не охотиться по `style.css`. Детали — [theming.md](theming.md).

## 5. Персистентность + галерея (как в Procreate) — 🔲

`core/storage.js` — документы в IndexedDB (localStorage мал для картинок):
слои, палитра, превью (PNG), размеры, время правки.

`systems/gallery.js` — **стартовый экран** в стиле Procreate:

- Тёмный фон, **сетка плиток** работ; под плиткой — название и размер
  (`64×64 px`). Тап по плитке → открывается редактор ровно на том месте.
- Верхняя панель галереи: слева заголовок, справа действия —
  **`+` Новый документ · Импорт (картинка) · Конвертер (фото → пиксель-арт)**
  (эти кнопки переезжают из тулбара редактора сюда) · **Select** (мультивыбор
  плиток: удалить/дублировать/в стопку).
- Долгий тап по плитке — контекст (переименовать, дублировать, удалить,
  поделиться/экспорт). Превью генерируется из композита при сохранении.
- Автосохранение активной работы; при следующем заходе открывается галерея,
  а не последний документ (Procreate-поведение).

Опирается на §1 (единая модель документа в `core/state`) и переиспользует
`compositeLayers` для превью, `placeImageLayer`/`sampleGrid` для импорта.

## 6. Готовность к анимации (точка расширения) — 🔲 (заложить заранее)

Цель: добавление анимации = «вставил модуль», без правок остальных систем.

- Модель документа расширяется понятием **кадров**: текущий «документ» — это
  кадр; контейнер хранит `frames: [doc]` + `fps`. Пока кадр один — поведение
  прежнее.
- Будущая `systems/animation/*` (таймлайн, onion-skin, экспорт GIF/спрайт-листа)
  читает/пишет `state.frames` и шлёт события в `bus`; рендер/слои её не знают.
- Сейчас фиксируем только контракт (см. [architecture.md](architecture.md) →
  «Точки расширения»), чтобы потом не ломать модель.

## Принцип

Ничего из §2–§6 не вмерживается, пока не зелёный `npm test` и (для интерактива)
ручная проверка в браузере. Каждый пункт — отдельная порция, рабочая на каждом
коммите.
