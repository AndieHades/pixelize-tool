# Дорожная карта

North star: **«Procreate для пиксель-арта»** — галерея работ, жесты,
тач-first, чистый интерфейс, профессиональные инструменты.

Порядок продуман так, что каждый пункт опирается на предыдущий и не ломает
работающее приложение. Статус: ✅ готово · 🟡 идёт · 🔲 ждёт.

## 1. Чистая архитектура без дублей — ✅

Перевод монолита `js/*` (общий глобальный scope) на слои `src/{logic,core,systems}`.
Прогресс и карта модулей — в [systems.md](systems.md). Сделано: слои `state`/`bus`,
DOM-фундамент, **вся чистая логика**, дедуп-утилиты, safety-net (`npm test`).

## 2. Сборка Vite + деплой — ✅ (живой деплой на Pages)

- `vite.config.js`, скрипты `dev`/`build`/`preview`, CI `.github/workflows/deploy.yml`
  (Node 22; `npm test` → `vite build` → publish). Source: Pages → «GitHub Actions».
- **PWA**: `manifest.webmanifest`, `sw.js` (network-first), иконки лежат в `public/`
  и отдаются как есть из корня (`/pixelize-tool/…`) — «На экран „Домой“» работает.
- На iPad открывается готовый статический `dist/`.

## 3. Локализация (i18n) — ✅

Все UI-строки → `t('ключ')`, тексты в `src/i18n/locales/{ru,en}.js`.
ru — дефолт (текущий), en — полный перевод. Детали и правила — [i18n.md](i18n.md).
Добавить язык = один новый файл локали. Сделано: система t(), ru/en (паритет
ключей), тултипы/меню/диалоги/тосты через t(), переключатель языка.

## 4. Темизация токенами — ✅

Цвета/размеры/отступы → CSS-переменные в одном месте. Менять тему = править
токены, не охотиться по CSS-файлам. Детали — [theming.md](theming.md).
Сделано: `src/styles/tokens.css` (цвета+размеры), светлая тема `[data-theme=light]`,
переключатель темы; цвета холста тоже из токенов (тема меняет и canvas).

## 5. Персистентность + галерея (как в Procreate) — ✅ (интерактив — браузер-QA)

`core/storage.js` — документы в IndexedDB (localStorage мал для картинок):
слои, палитра, превью (PNG), размеры, время правки.

`systems/gallery.js` — **стартовый экран** в стиле Procreate:

- Тёмный фон, **сетка плиток** работ; под плиткой — название и размер
  (`64×64 px`). Тап по плитке → открывается редактор ровно на том месте.
- Верхняя панель галереи: слева заголовок, справа действия —
  **`+` Новый документ · Импорт (картинка) · Конвертер (фото → пиксель-арт)**
  (эти кнопки переезжают из тулбара редактора сюда) · **Select** (мультивыбор
  плиток: удалить/дублировать/в стопку).
- Долгий тап по плитке — контекст (переименовать, дублировать, удалить,
  поделиться/экспорт). Превью генерируется из композита при сохранении.
- Автосохранение активной работы; при следующем заходе открывается галерея,
  а не последний документ (Procreate-поведение).

Опирается на §1 (единая модель документа в `core/state`) и переиспользует
`compositeLayers` для превью, `placeImageLayer`/`sampleGrid` для импорта.

## 6. Готовность к анимации (точка расширения) — ✅ контракт, 🔲 реализация

Цель: добавление анимации = «вставил модуль», без правок остальных систем.

- Animator открывается кнопкой сверху рядом с Reference, а таймлайн живёт в
  отдельном нижнем dock, не в панели слоёв.
- Модель документа расширяется понятием **кадров и таймлайнов**: выбранный кадр
  загружается в обычные `S.layers`/`S.folders`/`S.bg`, поэтому видимость слоёв
  хранится отдельно на каждом кадре.
- Операции со слоями относятся к активному кадру; resize/crop/rotate canvas
  применяются ко всем кадрам.
- History и autosave проектируются отдельно: обычный мазок не копирует весь
  Animator, а сохранение документа сначала сбрасывает активный кадр в модель.
- Закрытие Animator только прячет панель; работа сохраняется в документе и
  автосейве.
- Кадры можно создавать, выбирать, перетаскивать, дублировать и удалять через
  ПКМ/long-tap меню.
- Таймлайны можно создавать, переключать и переименовывать.
- Drag/drop GIF сразу создаёт/открывает Animator и раскладывает GIF по кадрам
  с переносом delays и loop-mode.
- Подробный план модулей и фаз — [animation.md](animation.md).

## 7. Продуктовая полировка (Procreate-уровень) — 🟡 идёт

Поверх §1–§6, отдельными порциями (каждая — рабочий коммит, браузер-QA):

- **Галерея**: вложенные папки; кнопки сбоку (Photo/Convert/Import-PSD/Select/＋/⚙);
  «Новый холст» — список пресетов + кастомные размеры (свайп/ПКМ → правка/удаление);
  drag плиток (перестановка, в папку, на «назад» — на уровень выше); ПКМ-меню;
  иконка папки у всех папок; уникальные имена (`Папка 01…`); конвертер/＋ — поверх
  галереи, не закрываются по фону.
- **Слои**: вложенные группы; глаз-видимость; Lock/Alpha-Lock (запрет правки/только
  по пикселям) + обтравка; мультивыбор (активный ярче, отмеченные приглушённо) —
  драг/группировка/удаление как над одним; щипок двух строк → слияние;
  свайпы (тач) и ПКМ-меню (десктоп); симметрию можно выключить на конкретном слое.
- **Жесты/UX, единые механики**: общий гост перетаскивания (`drag-ghost`), общая
  анимация нажатия (`btn-recoil`), меню-баблы со стрелкой (`showMenuAt`),
  перестановка кнопок панелей (`reorder-drag`, как цвета палитры).
- **Управление по типу устройства** (`isDesktop`): тач — свайпы/долгий тап; десктоп —
  ПКМ-меню, контекст-меню только ПКМ, курсор кисти только над холстом.

## 8. Tileset / Tilemap (Aseprite Tiles) — 🔲 спланировано

Слой нового типа: клетки хранят `tileId` + transform-флаги (не пиксели),
источник пикселей — тайлсет; правка тайла обновляет все экземпляры на карте.
Встраивается без переписывания рендера: `L.grid` tilemap-слоя — это кеш
растеризации, поэтому композит/экспорт/история/миниатюры работают как есть.
Полный дизайн, раскладка модулей по слоям и фазы — в
[tileset-tilemap.md](tileset-tilemap.md). Готовит почву под autotiling / terrain
/ animated tiles.

ручная проверка в браузере. Каждый пункт — отдельная порция, рабочая на каждом
коммите.
