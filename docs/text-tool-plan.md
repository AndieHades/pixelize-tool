# Text Tool: план и мокап

## Цель

Добавить полноценный инструмент текста для Pixel Heart: кнопку на панели инструментов, отдельный тип текстового слоя, редактирование текста прямо на холсте и окно шрифтов в стиле текущих панелей палитр, кистей и стилей.

Первую версию стоит делать как редактируемый текстовый слой с растровым кешем: исходные данные текста остаются живыми, а существующие эффекты, экспорт, прозрачность, видимость и порядок слоев продолжают работать через `grid`.

Мокап: [docs/mockups/text-tool-mockup.html](mockups/text-tool-mockup.html)

## UX-контракт

- В toolbar появляется кнопка Text с понятной иконкой `T`.
- Кисть остается инструментом по умолчанию.
- Повторный клик ЛКМ по активному Text выключает его и возвращает кисть.
- Нажатие Text в toolbar открывает окно шрифтов и включает режим текста.
- Окно шрифтов не исчезает само: его можно оставить открытым, перенести, растянуть или закрыть вручную.
- Клик по холсту активным Text создает новый текстовый слой в точке клика, сразу делает этот слой активным и включает ввод текста.
- Двойной клик по тексту на холсте включает inline-редактирование этого текста.
- Двойной клик по текстовому слою в панели слоев тоже включает редактирование текста на холсте.
- Выделенный текст на холсте можно сразу переписать, стереть через Backspace/Delete, частично удалить, очистить целиком и переносить как объект.
- Текстовый слой можно двигать, трансформировать, скрывать, блокировать, переименовывать, переставлять, клиппировать и обрабатывать эффектами как обычный слой.
- Обводка, тень, glow и похожие эффекты применяются к растровому кешу текстового слоя.
- Окно шрифтов - floating panel в стиле палитр, кистей и стилей.
- В окне шрифтов основная область занята квадратными тайлами шрифтов с превью и названием.
- Клик по тайлу шрифта сразу меняет шрифт выбранного текстового слоя.
- Если текстовый слой не выбран, клик по тайлу меняет шрифт по умолчанию для следующего текста.
- Активный шрифт подсвечен синим активным состоянием.
- Шрифты можно переименовывать, удалять, менять местами drag-and-drop и сохранять между запусками.
- При большом количестве шрифтов область тайлов прокручивается.
- Drag-and-drop `.ttf`, `.otf`, `.woff`, `.woff2` в окно шрифтов сразу добавляет шрифт без видимой зоны или надписи `Drop font`.
- Нижняя часть окна - одна строка: размер, слайдер, значение в пикселях и круг текущего цвета.
- Размер выглядит как `Непрозрачность` в слоях: подпись/тоггл, горизонтальный трек, круглый бегунок, значение в пикселях, живое изменение выбранного текста.
- В строке непрозрачности у слоев подпись убирается: процент остается на месте подписи, перед слайдером.
- Добавление шрифта открывается плюсиком в шапке окна, как в окне кистей.
- Rename/Delete находятся в контекстном меню плитки шрифта по ПКМ.
- Цветовой круг открывается по клику на круг цвета.
- Изначальный цвет в круге - активный цвет текста.
- При изменении цвета в цветовом круге цвет выделенного текста меняется в реальном времени.
- Последний выбранный шрифт, цвет и размер сохраняются между документами и перезапусками приложения.
- При выходе из документа непрозрачность слоев сохраняется вместе с документом.
- Макет и реализация используют существующие стили: floating window, header actions, brush/font tiles, lower action rows, range controls, tokens. Новый визуальный стиль не вводится.

## Модель данных

Текст не должен запекаться в обычный пиксельный слой. Нужен отдельный `kind`.

```js
{
  kind: 'text',
  id,
  name,
  visible,
  opacity,
  lock,
  clip,
  effects,
  grid,
  text: {
    value: 'Text',
    fontId: 'builtin-pixel',
    size: 16,
    color: '#ffffff',
    align: 'left',
    lineHeight: 1,
    letterSpacing: 0,
    box: { x: 0, y: 0, w: 96, h: 32 },
    transform: { x: 0, y: 0, scaleX: 1, scaleY: 1, rotation: 0 }
  }
}
```

`text` - редактируемый источник, `grid` - отрисованный кеш. Любое изменение текста, шрифта, размера, цвета или трансформации обновляет `grid` и помечает слой грязным.

Шрифты должны быть глобальными данными приложения, а не только частью одного документа:

```js
{ id, name, family, format, builtin, order, createdAt, updatedAt }
```

Бинарные данные импортированных шрифтов лучше хранить в IndexedDB. Там же можно держать имена, порядок и состояние удаления, чтобы импортированные шрифты переживали перезапуск приложения.

Последние настройки текста лучше хранить как app prefs рядом с похожими настройками кисти:

```js
{ fontId: 'builtin-pixel', size: 16, color: '#ffffff' }
```

При создании нового текстового слоя эти значения копируются в `layer.text`. Дальше слой хранит собственные параметры, а prefs обновляются при выборе другого шрифта, размера или цвета в окне шрифтов.

## Рендеринг

- Регистрировать импортированные шрифты через `FontFace` при старте приложения и сразу после импорта.
- Растеризовать текст через offscreen canvas в `grid` слоя.
- Держать вывод pixel-snapped и не сглаживать копирование в пиксельную сетку.
- Перерисовывать кеш только при изменении исходных данных текста.
- Сохранять исходные данные текста в истории, чтобы undo/redo не ломали редактируемость.
- На первом этапе экспорт может отдавать текст как растр, потому что композит уже работает через `grid`.

## Системы и файлы

- `src/config/text.js`: дефолтный шрифт, размер, диапазон размера, форматы импорта, лимит файла.
- `src/core/text-layer.js`: фабрика текстового слоя, нормализация, clone/serialization, обновление кеша.
- `src/core/font-store.js`: IndexedDB для шрифтов, порядок, import/delete/rename.
- `src/core/text-prefs.js`: последний выбранный `fontId`, `size`, `color` для следующего текста.
- `src/logic/text-model.js`: чистая валидация и нормализация настроек текста.
- `src/systems/text-tool/index.js`: создание текста, inline-редактирование, перенос, commit/cancel.
- `src/systems/font-library/panel.js`: floating panel, тайлы, импорт, reorder, rename, delete, размер, цвет.
- `src/systems/toolbar/*`: кнопка Text и иконка.
- `src/systems/layers/*`: иконка текстового слоя и двойной клик для редактирования.
- `src/i18n/locales/*`: все подписи, ошибки импорта, тосты и меню.
- `src/styles/parts/font-library.css`: только сборка из существующих токенов и паттернов floating panels, brush tiles, action rows, range controls.
- `test/unit.mjs`: модель текста, порядок шрифтов, границы размера.
- `test/module-int.mjs`: создание текста, выбор шрифта, live color/size, кеш слоя, persistence.

## Фазы

1. Основа: config, модель текста, `kind: 'text'`, миграция старых документов.
2. Растровый кеш: `FontFace`, rasterize, обновление `grid`, проверка эффектов и экспорта.
3. Инструмент Text: кнопка, открытие окна шрифтов, создание слоя в точке клика, двойной клик, inline editing, Backspace/Delete, перенос.
4. Окно шрифтов: перенос, resize, ручное закрытие, прокрутка тайлов, активное состояние, rename/delete/reorder, drag-drop импорт без видимой drop-зоны.
5. Нижняя панель: одна строка Size, слайдер, значение `px`, круг цвета и live color; плюсик добавления шрифта остается в шапке.
6. Persistence: сохранение opacity при выходе из документа, сохранение последнего шрифта, размера и цвета.
7. Полировка: ошибки импорта, missing-font recovery, экспорт/импорт данных приложения, touch targets.

## Критерии приемки

- Text появляется в toolbar и повторный клик возвращает кисть.
- Text открывает переносимое и растягиваемое окно шрифтов, которое не закрывается само.
- Клик по холсту в режиме Text создает `kind: 'text'` в точке клика, а не обычный пиксельный слой.
- Текст остается редактируемым после save/reload.
- Двойной клик по тексту или его слою включает редактирование на холсте.
- Выделенный текст переписывается, удаляется Backspace/Delete и переносится.
- Эффекты применяются к текстовым слоям и видны в canvas/export.
- Окно шрифтов визуально совпадает с семейством floating panels.
- Клик по тайлу шрифта сразу меняет выбранный текстовый слой.
- Размер меняется live через слайдер в стиле opacity у слоев, справа видно значение в `px`.
- Непрозрачность слоев показывает процент на месте бывшей подписи, перед слайдером.
- Плюсик в шапке открывает проводник Windows, а drag-drop импортирует шрифт без перезагрузки.
- ПКМ по плитке шрифта открывает контекстное меню Rename/Delete.
- Круг цвета открывает цветовой круг, стартует с активного цвета и меняет текст live.
- Импортированные шрифты сохраняются после перезапуска.
- Последний выбранный шрифт, цвет и размер применяются к новому тексту после смены документа или перезапуска.
- Непрозрачность слоя сохраняется после выхода из документа и возврата к нему.

## Пропорциональные проверки

- Для плана и мокапа: diff review и открыть HTML-мокап.
- Для модели данных: unit-тесты нормализации, сериализации и миграции.
- Для систем: module-int на создание, выбор, persistence, live color/size и обновление кеша.
- Для UI: ручная проверка pointer/touch, double-click, drag-drop, проводник Windows и цветовой круг.
- Перед пушем реализации: `npm run lint` и `npm test`.

## Открытые решения

- PSD export в первой версии: живой текст или raster-only.
- Встраивать ли импортированные шрифты в файл проекта.
- Объем типографики в первой версии: multiline, align, line-height, spacing, rotation.
- Удаление шрифта: сразу навсегда или через recoverable trash.
- Inline editing на холсте обязателен; окно шрифтов управляет шрифтом, размером и цветом, но не заменяет редактирование текста.
