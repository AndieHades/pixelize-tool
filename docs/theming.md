# Темизация (дизайн-токены)

Цель: поменять цвет/отступ/радиус = править **одно** место (токен), а не
искать значение по всему `style.css`.

## Устройство

Токены — CSS-переменные в `:root` (файл `src/styles/tokens.css`). Остальные
стили ссылаются только на них:

```css
:root {
  /* цвета */
  --col-bg:        #0d0d10;
  --col-panel:     #141419;
  --col-accent:    #ff7a18;
  --col-line:      rgba(255,255,255,.05);
  /* размеры */
  --btn:           40px;
  --radius:        12px;
  --gap:           8px;
  /* типографика */
  --font:          system-ui, sans-serif;
}

.tb-group button { width: var(--btn); border-radius: var(--radius); }
header { background: var(--col-panel); }
```

## Правила

- **Запрещены зашитые значения стиля** (hex-цвета, пиксели «магией») вне
  `tokens.css`. В правилах — только `var(--…)`.
- Имена токенов — по смыслу (`--col-accent`), а не по значению (`--orange`):
  тему меняем переопределением, не переименованием.
- Тёмная/светлая/другие темы — это другой набор значений тех же токенов
  (`:root[data-theme="light"] { --col-bg: … }`). Переключатель темы шлёт
  `bus.emit('theme')` и ставит `data-theme` на `<html>`.

Проверка «нет зашитых цветов вне токенов» (грубая):
```bash
grep -RnE "#[0-9a-fA-F]{3,8}|rgba?\(" src/styles --include='*.css' \
  | grep -v tokens.css && echo "вынеси в токен" || echo "ok"
```

## Связь с i18n

Переключатели языка и темы живут рядом (системные настройки приложения) и оба
работают по одному паттерну: меняют состояние → шлют событие в `bus` →
визуальные системы реагируют.
